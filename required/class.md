# 요가원 수업/출석 기능 정의서

## 📌 개요

요가원 운영을 위한 수업 등록, 회원 등록, 출석 체크, 횟수권 관리 기능을 Flutter 앱 내 "수업 탭"에 구현한다.  
회원은 네이버 예약 등 외부 수단을 통해 예약하며, 관리자는 예약 확인 후 앱에서 회원을 등록하고 출석을 관리한다.

---

## 👥 사용자 유형

- **관리자(요가원 선생님)**: 수업 등록, 회원 등록, 출석 체크 및 수강권 관리
- **회원(수강생)**: 앱을 설치하지 않으며 QR코드로 출석 또는 예약만 진행

---

## 🧩 기능 구성

### 1. 수업 관리

| 기능명 | 설명 |
|--------|------|
| 수업 등록 | 매월 반복되는 요가 수업을 생성한다 (예: 월수반 오전 10시) |
| 수업 편집 | 날짜/시간/강사 등의 수업 정보를 수정할 수 있다 |
| 수업 삭제 | 실수로 등록한 수업이나 취소된 수업은 삭제 가능 |
| 수업 목록 조회 | 월별, 주별로 수업 일정을 확인하고 관리할 수 있다 |

---

### 2. 수강권 관리

| 기능명 | 설명 |
|--------|------|
| 수강권 등록 | 회원별로 5회권/10회권 등 총 수강 가능 횟수를 등록 |
| 수강권 수정 | 남은 횟수 수동 조정 가능 (연장/복구 등 상황에 따라) |
| 자동 차감 | 출석 체크 시 1회 자동 차감됨 |
| 수강권 이력 확인 | 총 횟수 / 사용한 횟수 / 잔여 횟수 확인 가능 |

---

### 3. 출석 관리

| 기능명 | 설명 |
|--------|------|
| 수동 출석 체크 | 관리자가 수업별 회원 리스트에서 출석 버튼 클릭 |
| QR 코드 출석 체크 | 회원이 QR을 찍고 이름 or 전화번호 입력하여 출석 |
| 출석 상태 표시 | 출석 / 결석 / 지각 등으로 상태 표시 가능 (선택 사항) |
| 출석 로그 | 수업별, 회원별 출석 내역 기록 저장 |
| 출석 → 수강권 차감 | 출석 처리와 동시에 횟수권에서 1회 차감 |

---

### 5. QR 코드 출석 시스템

| 기능명 | 설명 |
|--------|------|
| QR 생성 | 수업마다 고유 출석 QR 코드 생성 |
| QR 스캔 후 출석 폼 | 회원이 이름 or 전화번호 뒷자리 입력 |
| 출석 기록 저장 | 해당 정보가 일치하면 출석 처리 및 차감 |
| 중복 방지 | 같은 수업 같은 회원의 이중 출석 방지 처리 필요 |
