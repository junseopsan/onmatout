# Project Overview (프로젝트 요약)
ONMATOUT은 입문자와 중급자를 타겟으로 효율적인 요가 수련을 도와주는 모바일 앱입니다. 사용자는 총 300개의 요가 아사나 카드를 활용해 오늘 수련한 아사나를 선택하여 루틴을 저장할 수 있으며, 수련 기록을 남기고 성장 과정을 확인할 수 있습니다. ONMATOUT은 요가를 처음 접하는 사람도 쉽게 시작할 수 있게 돕고, 꾸준히 수련하며 요가를 일상 습관으로 만들 수 있도록 유도합니다.

# Core Functionalities (핵심 기능)

1. 요가 아사나 카드 리스트
- 총 300개의 요가 아사나 카드 제공
- 자세 이미지, 이름, 설명, 레벨, 효과, 스토리 포함

2. 아사나 상세 보기
- 자세 이름, 카테고리, 레벨, 이미지, 설명, 효과, 스토리 등의 정보 제공

3. 수련 기록 기능
- 사용자가 선택한 아사나 수련 완료 시 기록
- 감정 상태 이모지 선택 + 간단한 메모 작성 가능
- 수련 통계: 누적 수련 횟수, 연속 수련 일수 등 시각화

4. 수련 완료 보상 및 도장 시스템
- 루틴 수행 완료 시 도장 표시 또는 카드 수집 효과로 성취감 제공
- 수련 완료 시 사용자 피드백 문구 노출 (예: "잘하셨어요! 오늘도 수고하셨습니다.")

5. 오늘의 루틴 저장 기능
- 오늘 수련한 아사나를 선택하여 루틴으로 저장
- 저장된 루틴은 수련 기록과 함께 관리
- 루틴에 대한 간단한 메모 작성 가능
